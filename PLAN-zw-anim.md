# PLAN — Анимации и микровзаимодействия HTML-иллюстраций zw-блока

> Всё работает на тест-странице zw-html-test.html. Библиотек не подключаем — CSS keyframes/transitions + rAF-счётчики. Всё перезапускается при каждом включении кадра (класс is-on), выключается при prefers-reduced-motion.
> Файлы: дополнение css/zw-art.css + новый js/zw-anim.js.

---

## 0. Общий каркас

1. **Триггер**: JS вешает на `.zw-shot--art.is-on` класс `.is-live` в момент активации кадра (и снимает при уходе) → все CSS-анимации кадра перезапускаются автоматически.
2. **Счётчики** (единая функция): `countUp(el, from, to, dur, format)` на rAF, easeOutCubic. Форматы: «58», «25/100», «56%», «50 007» (неразрывный пробел), «6%».
3. **Тайминги**: появление элементов 450–650ms, stagger 90–110ms, easing `cubic-bezier(.2,.7,.2,1)`. Счётчики 700–900ms.
4. **prefers-reduced-motion**: классы анимаций не навешиваются, счётчики ставятся в конечные значения сразу.
5. **Курсор**: pointer только на реальных контролах (кнопки доступа, копирка, Сохранить, крестик, теги-пилюли).

## 1. Кадр «Поделиться ссылкой» — полностью интерактивный

- **Кнопки доступа** (Только я / По ссылке / Для всех):
  - hover: фон `rgba(255,255,255,.05)` (неактивным) — плавно 150ms.
  - клик: «стеклянная» активная подсветка (фон .08 + тени + блюр) переезжает на нажатую — анимированно: активная подложка — отдельный абсолютный элемент, плавно меняет left (200ms cubic).
- **Копирование ссылки**:
  - hover на копирку: фон `rgba(255,255,255,.06)`.
  - клик: иконка копирования → **зелёная галочка** (pop-in 180ms), тост «Ссылка скопирована» (маленький, снизу по центру инпута, fade+slide 200ms), через 1.8с галочка → иконка копирования, тост гаснет.
  - сам clipboard: `navigator.clipboard.writeText` с fallback на `execCommand` (localhost — secure context ✓).
- **Кнопка «Сохранить»**:
  - hover: чуть светлее (#fff) + translateY(-1px).
  - клик: текст → **мини-спиннер** (600ms) → **зелёная галочка + «Сохранено»** (400ms) → тост «Успешно сохранено» → через 1.6с возврат к «Сохранить».
- **Крестик (×)**: клик — модалка схлопывается (scale .97 + fade, 250ms), через 1.4с разворачивается обратно (появление = «переоткрыл ссылку»).
- **Инпут ссылки**: hover — обводка `rgba(255,255,255,.08)`.
- Появление кадра: инпут и кнопки въезжают стаггером (контейнер → заголовок → кнопки → инпут → Сохранить).

## 2. Кадр «Индекс доверия» — цифры и дуга

- **Дуга**: при активации рисуется `stroke-dashoffset` от полной до 58% (800ms easeOut) — синхронно со счётчиком.
- **Счётчик 58** (+ «/100» статично): 0→58 за 800ms easeOutCubic.
- **Игла**: разворачивается от стартового угла к 58% (rotate, 800ms, тот же easing) — «стрелка доезжает».
- **Шкала внизу**: белая точка выезжает 0→58% (800ms), пилюля «58/100» pop-in (scale .6→1) на финише.
- **Счётчики карточки Udodov**: 298, 50 007, 78 (стаггер 90ms), 56%, 2%, 39% — count-up при активации; полоски-заполнители (уверенность/эго/конфликт) растут слева направо синхронно с процентами.
- **Hover**: карточка Удодова — translateY(-2px) + тень чуть глубже (150ms); пилюля «Полный AI» — подсветка фона; «25/100» — ничего (не контрол).
- Появление кадра: карточка Удодова въезжает справа (translateX(30px)→0 + fade, 500ms), гейдж-карточка — снизу (translateY(24px)→0 + fade) стаггером.

## 3. Кадр «Схема» (что читает сервис)

- **Каскад появления**: верхняя карточка → три мини (стаггер 100ms) → Сотни метрик → ИИ-портрет → Готовое досье: opacity + translateY(16px)→0, 450ms каждый.
- **Коннекторы «прочерчиванием»**: развилка и три вертикали переводятся в inline-SVG с dashed-штрихом; анимация stroke-dashoffset (600ms) после появления карточек своего яруса.
- **Hover карточек**: translateY(-2px) + фон .05→.065 (150ms) — «живой дашборд».
- **Пилюли** (Источник/Анализ/AI/Результат): pop-in (scale .7→1 + fade) с задержкой после своей карточки.
- **Зелёная иконка «Готовое досье»**: мягкий пульс свечения (box-shadow 0→4px, 2.4s loop) — финальный акцент схемы.

## 4. Кадр «О досье»

- **Скелетоны**: в пустых карточках — **shimmer**: диагональная световая полоса бежит по плашкам (1.6s loop, ease-in-out). Это «загрузка» по твоей идее.
- **Весы (Признание ошибок)**: при появлении — взвешивание: коромысло качается rotate 0→±3° (2 цикла, 2.2s) и останавливается; чашки приезжают со своими «2»/«3» (fade+scale).
- **Эго-кольцо**: 24 точки загораются по кругу стаггером (по 30ms), верхняя — зелёная с glow в конце; одновременно счётчик «6%» (0→6) и «83» (0→83).
- **Слово-вердикт**: «Сдержанное эго» — fade-in после остановки колец.
- **Glows**: деликатное «дыхание» (opacity .8→1, 3s loop) — опционально, выключаемо.
- Появление кадра: карточки сетки въезжают стаггером (как в схеме), вкладка «Психология» в навигации — уже активная.

## 5. Технические заметки

- Анимации — только `transform`/`opacity` (+ stroke-dashoffset в SVG). Блюры/glows статичны, «дышат» только opacity.
- Конфликт с `will-change:backdrop-filter` на стекле — не трогаем, блюр живёт сам.
- Перезапуск: снятие/установка `.is-live` — дешёвый рестарт всех keyframes; rAF-счётчики отменяются при уходе с кадра.
- При порте в лендинг: файлы zw-anim.js + правила в zw-art.css едут вместе с артами; entrance-fade фигур оставить только transform-ом (opacity-fade на контейнере с backdrop-фильтром даёт вспышку «без блюра» — см. round 10-11).
