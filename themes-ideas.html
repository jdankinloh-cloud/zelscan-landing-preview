Темы для блока — v2

Убрал кредиты (у нас рубли), динамику (мелочь для целого столбца) и конвейер (уже показан). Каждая тема ниже — самостоятельная фича продукта, которой нет на странице. Экраны — реальные страницы 1:1 или с минимальной правкой.

01

Индекс доверия — одна цифра перед сделкой

Отчёт сводит репутацию, конфликты и поведение в один индекс 0–100. Открыл — понял, можно ли иметь дело. На лендинге индекса нет вообще.

1:1 · анализ
Полукруглый гейдж «35/100 · умеренно» со стрелкой — реальный экран страницы «Анализ».
1:1 · мои досье
Карточка досье с плитой «Репутация 35/100» (жёлтая цифра) — как в списке «Мои досье».
правка гейджа
Гейдж крупно на весь кадр + снизу три составляющих: репутация · конфликты · поведение (подписи из отчёта).
02

Досье — это 5 разделов, а не одна карточка

Обзор → Активность → Поведение → Психология → Анализ. Каждый раздел — свои экраны и выводы. На лендинге показан только кусок «Обзора».

1:1 · отчёт
Панель вкладок Обзор | Активность | Поведение | Психология | Анализ с активной вкладкой — реальный переключатель из отчёта.
1:1 · психология
Тайлы «Психологии»: Уверенность 43% (сфера-лицо), Психологический возраст 31, Признание ошибок (весы).
1:1 · анализ
LED-полосы приёмов: Провокация / Скрытность / Сарказм / Упёртость / Теплота / Открытость — реальный блок страницы «Анализ».
03

Поведение: как человек на самом деле общается

Манера речи, типажи, триггеры и реальные фразы из постов. Про стиль общения — на странице такого раздела нет.

1:1 · поведение
Чипы-типажи «Токсик» «Шарит» «Тролль» «Душа» + строка вердикта — как в карточке досье, но крупно.
1:1 · поведение
«Примеры фраз»: цитаты реальных постов курсивом «да бывает такое что не…» — список из страницы «Поведение».
1:1 · поведение
«🎯 Триггеры»: карточки того, что выводит профиля из себя — реальный блок страницы.
04

Что читает сервис — и откуда

Источник один — lolz.team. Профиль: ник, ID, дата регистрации. Контент: темы, посты, сообщения. Активность: частота, репутация, динамика. Результат — интерпретация поведения аккаунта, а не человека в жизни.

1:1 · отчёт
Hero профиля: ник, ID, стаж на форуме + описание — всё это данные, которые сервис читает из API.
1:1 · активность
Разделы «Где обитает» и «Стена профиля» — реальные страницы данных аккаунта.
1:1 · модерация
Секция «02 / Данные» со страницы для модерации: список Источник / Профиль / Контент / Активность / Результат — готовый экран, текст уже написан.
05

Чего Zelscan не делает — никогда

Не использует сторонние OSINT-сервисы и базы утечек. Не ищет имя, дату рождения, адрес. Не ищет телефон, почту, соцсети. Не сопоставляет профиль с человеком. Деанон — не про нас.

1:1 · модерация
Секция «03 / Ограничения» со страницы для модерации: 5 строк-ограничений — готовый экран, текст уже написан.
1:1 · дашборд
Hero дашборда со строкой «🛡 Работаем исключительно с публичной информацией» — тезис уже есть в интерфейсе.
правка модерации
Список ограничений крупно на весь кадр + иконка замка сверху — единственная добавка.
06

Отчёт живёт по ссылке — досье можно показать

Кнопка «Поделиться» в отчёте и публичные досье: разбор можно открыть продавцу, напарнику, в теме.

1:1 · отчёт
Шапка отчёта с кнопкой «🔗 Поделиться» — она уже есть рядом с именем.
1:1 · публичные досье
Страница «Публичные досье» — лента готовых разборов, витрина сервиса.
правка отчёта
Шапка отчёта + раскрытая ссылка zelscan.xyz/d/ZS-CD626639 (реальный номер досье).
